اجزای پایپینگ

شناخت کامل لوله، فلنج، اتصالات، شیرها، گسکت و بولتینگ — با مرجع استانداردهای ASME، API و MSS

یک خط لوله (Piping Line) از مجموعه‌ای از اجزای استاندارد تشکیل شده: لوله به‌عنوان بدنه اصلی، اتصالات برای تغییر مسیر و انشعاب، فلنج برای نقاط قابل بازشو، گسکت و بولتینگ برای آب‌بندی، و شیر برای قطع و تنظیم جریان. هر جزء استاندارد ابعادی، کلاس فشاری و الزامات متریال خاص خود را دارد — و همه باید با Pipe Class خط سازگار باشند.

نکته بحرانی
طبق ASME B31.3, Chapter III (Para. 304–314)، رتینگ هر جزء باید با شرایط طراحی خط سازگار باشد. در عمل، کلاس تمام اجزا از PMS (Pipe Class) گرفته می‌شود — نصب فلنج Class 150 روی خط Class 300 ممنوع است، حتی اگر از نظر ظاهری «کافی» به نظر برسد.

اجزای تشکیل‌دهنده یک خط لوله

LINE
Piping Line Anatomy روی هر جزء کلیک کنید تا نقش آن در خط لوله نمایش داده شود

قبل از ورود به جزئیات، تصویر کلی را ببینید. یک خط فرآیندی ساده حداقل شش خانواده جزء دارد. روی هر کدام کلیک کنید:

Pipe — لوله

بدنه اصلی حامل سیال. سایز با NPS (اینچ) و ضخامت با Schedule مشخص می‌شود. در سرویس‌های فرآیندی معمولاً بدون درز (SMLS) یا درزجوش با کیفیت بالا استفاده می‌شود.

ASME B36.10M / B36.19M SMLS / ERW / SAW بیشترین سهم MTO
۲

لوله (Pipe)

PIPE
Pipe سایز، Schedule و روش ساخت — پایه تمام محاسبات خط

لوله با سه پارامتر تعریف می‌شود: سایز اسمی (NPS)، ضخامت دیواره (Schedule) و روش ساخت. نکته کلیدی این است که OD لوله برای هر NPS ثابت است و با تغییر Schedule فقط ضخامت دیواره عوض می‌شود — یعنی اتصالات یک سایز، با همه Schedule ها جفت می‌شوند.

تا NPS 12، عدد NPS با قطر واقعی برابر نیست (مثلاً NPS 12 یعنی OD ≈ 323.9mm)؛ از NPS 14 به بالا، OD دقیقاً برابر NPS×25.4 می‌شود. همچنین برای سایزهای ≤ 12"، Sch 40 همان STD و Sch 80 همان XS است — اما از 14" به بالا دیگر STD/XS معنی ندارد و فقط ضخامت ذکر می‌شود.

فلنج‌ها (Flanges)

FLG
Flanges اتصال قابل بازشو — تایپ، Face و کلاس فشاری

فلنج جایی استفاده می‌شود که اتصال باید قابل باز شدن باشد: اتصال به تجهیزات، شیرها و نقاط نیازمند تعمیرات. انتخاب فلنج سه بعد دارد: تایپ اتصال به لوله (WN، SO، …)، نوع سطح آب‌بندی (RF، RTJ، FF) و کلاس فشاری (150 تا 2500).

تایپ فلنج اختصار اتصال به لوله کاربرد نکته فنی
Weld Neck WN جوش شیاری (BW) سرویس‌های فرآیندی، دما/فشار بالا، بار سیکلی بهترین توزیع تنش — پرکاربردترین در پایپینگ فرآیندی
Slip-On SO دو جوش فیللت فشار پایین، سرویس غیربحرانی (Utility) مقاومت خستگی کمتر از WN — ارزان‌تر
Blind BL — بستن انتهای خط، ایزولاسیون برای تست بیشترین تنش خمشی — بولتینگ کامل
Socket Weld SW سوکت + جوش فیللت سایز کوچک ≤ 2" گپ 1.5mm قبل از جوش الزامی
Threaded THD رزوه NPT جاهایی که جوشکاری مجاز نیست نه برای دما/فشار بالا یا سرویس سیکلی
Lap Joint LJ همراه Stub End سرویس‌های نیازمند بازشدن مکرر، متریال گران فلنج آزاد می‌چرخد — الاینمنت سوراخ‌ها آسان
Raised Face (RF) رایج‌ترین Face — با گسکت Spiral Wound یا Sheet
Ring Type Joint (RTJ) سرویس فشار بالا — گسکت حلقه فلزی (Class ≥ 600)
Flat Face (FF) اتصال به تجهیزات چدنی — جلوگیری از شکست
کلاس‌های فشاری 150 / 300 / 600 / 900 / 1500 / 2500
خطر — تطابق Face و گسکت
فلنج RTJ فقط با گسکت Ring Type Joint و فلنج RF فقط با گسکت RF جفت می‌شود — این دو هرگز قابل تعویض نیستند. همچنین «کلاس» به تنهایی فشار مجاز را نمی‌دهد: فشار مجاز هر کلاس تابع متریال و دماست (جداول ASME B16.5 Table 2 برای گروه‌های متریال).

شیرها (Valves)

VLV
Valves قطع، تنظیم و حفاظت جریان — انتخاب بر اساس وظیفه

شیر بر اساس «وظیفه» انتخاب می‌شود: قطع و وصل (On/Off)، تنظیم جریان (Throttling) یا جلوگیری از برگشت جریان (Non-Return). انتخاب شیر اشتباه — مثلاً Gate برای تنظیم جریان — باعث سایش، کاویتاسیون و خرابی زودرس می‌شود.

شیر وظیفه استاندارد اصلی کاربرد / نکته
Gate On/Off API 600API 602 افت فشار کم در حالت باز — هرگز برای Throttling
Globe On/Off + Throttling BS 1873API 602 کنترل دقیق جریان — افت فشار بالا
Ball On/Off سریع API 6DAPI 608 Full-Bore برای خطوط Pig-رو — Trunnion برای سایز/فشار بالا
Check (Swing / Dual Plate) ضدبرگشت جریان API 594BS 1868 بعد از پمپ و کمپرسور — جهت نصب طبق فلش بدنه
Butterfly On/Off + Throttling سایز بزرگ API 609 سبک و اقتصادی برای آب و سایزهای بزرگ
Plug On/Off، سیالات لجنی API 599 سرویس‌های با ذرات جامد — قابلیت چندپورته
نکته انتخاب
در خطوط کوچک (≤ 2") معمولاً شیرهای Compact با استاندارد API 602 (اتصال SW یا رزوه‌ای) استفاده می‌شود؛ در خطوط فرآیندی بزرگ‌تر، API 600 (Gate فولادی) و API 6D (Ball خطوط انتقال). نوع اتصال (Flanged / BW / SW) همیشه از Pipe Class گرفته می‌شود.
هشدار نصب
شیر Check باید طوری نصب شود که مکانیزم آن با گرانش و جهت جریان سازگار باشد (Swing Check افقی یا صعودی). نصب Gate Valve به‌جای Globe برای تنظیم جریان، باعث وایبریشن دیسک و خرابی Seat می‌شود.
۵

اتصالات و انشعاب‌ها (Fittings & Branch)

FIT
Fittings تغییر مسیر، تغییر سایز و انشعاب — BW، SW و رزوه‌ای

اتصالات بر اساس نوع اتصال به سه خانواده تقسیم می‌شوند: جوش شیاری (Butt-Weld، پرکاربردترین در فرآیند)، ساکت‌ولد و رزوه‌ای (سایز کوچک و Utility). در سایزهای بزرگ و سرویس‌های بحرانی، فقط Butt-Weld مجاز است.

جزء استاندارد انواع نکته فنی
Elbow ASME B16.9 90° / 45° — LR (1.5D) / SR (1D) LR رایج‌ترین — SR فقط در فضای تنگ
Tee ASME B16.9 Straight / Reducing برای انشعاب‌های بزرگ — تقویت Branch طبق B31.3
Reducer ASME B16.9 Concentric / Eccentric Eccentric در مکش پمپ — جلوگیری از حبس هوا
Cap ASME B16.9 — بستن انتهای خط (موقت یا دائم)
Olet (Weldolet / Sockolet) MSS SP-97 Weldolet, Sockolet, Threadolet, Elbolet انشعاب تقویت‌شده سایز کوچک — جایگزین اقتصادی Tee
اتصالات SW / رزوه‌ای ASME B16.11 Elbow, Tee, Coupling, Union — Class 3000/6000/9000 فقط سایز ≤ 2" و سرویس غیربحرانی
نکته کلاسیک میدانی
در خط مکش پمپ (افقی)، Reducer باید Eccentric با سمت تخت رو به بالا (Flat Side Up) نصب شود تا حباب هوا زیر سقف Reducer جمع نشود و از کاویتاسیون جلوگیری شود. در خطوط عمودی یا خروجی پمپ معمولاً Concentric استفاده می‌شود.

گسکت‌ها و بولتینگ (Gaskets & Bolting)

GSK
Gaskets & Bolting قلب آب‌بندی اتصال فلنجی — گسکت + بار بولت

آب‌بندی اتصال فلنجی حاصل سه عامل است: سطح Face سالم، گسکت مناسب و بار یکنواخت بولتینگ. گسکت با فشار بولت فشرده (Seating) و در سرویس باید در برابر فشار داخلی و دما مقاومت کند. انتخاب گسکت از جداول Pipe Class و بر اساس سیال/دما انجام می‌شود.

گسکت استاندارد Face فلنج کاربرد
Spiral Wound (با Inner/Outer Ring) ASME B16.20 RF رایج‌ترین در فرآیند — کلاس 150 تا 2500
Ring Type Joint (RTJ) ASME B16.20 RTJ فشار/دمای بالا — حلقه فلزی Oval یا Octagonal
Non-Asbestos Sheet ASME B16.21 FF / RF کلاس پایین آب، Utility و سرویس‌های کم‌فشار
Camprofile / Kammprofile ASME B16.20 RF سرویس سیکلی دمایی — مبدل‌ها و خطوط بخار
بولتینگ استاندارد کاربرد نکته
Stud Bolt B7 + Nut 2H ASTM A193 / A194 سرویس CS تا حدود +425 °C رایج‌ترین ترکیب در پایپینگ فرآیندی
B8 / B8M + Nut 8 / 8M ASTM A193 / A194 فلنج‌های SS و سرویس خورنده Anti-seize الزامی — گریپاژ SS
L7 / 4L ASTM A320 / A194 سرویس دمای پایین (Cryogenic) تست ضربه در دمای سرویس
خطر — استفاده مجدد ممنوع
گسکت استفاده‌شده هرگز دوباره نصب نمی‌شود (اسپیرال پس از کمپرس شدن خاصیت ارتجاعی خود را از دست می‌دهد). بولتینگ باید طبق رویه گشتاور (Torque Procedure) و به‌صورت الگوی ستاره‌ای/متقاطع و در چند Pass کشیده شود؛ انتهای Stud باید حداقل دو رزوه از مهره بیرون بزند.
